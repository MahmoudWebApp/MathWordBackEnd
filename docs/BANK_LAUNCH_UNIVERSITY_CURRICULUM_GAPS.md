## Critical distinction: 26 module gaps are not automatically 26 new categories
Existing broad categories overlap the proposed modules. In particular 14 already contains determinant, independence, dot product, trace and vector scaling; 15 already contains first-order ODEs and second-order IVPs; 24 already contains logic, graphs, combinatorics, relations and proofs; 89 already contains confidence intervals, tests and sampling distributions; 90 already contains errors, linear systems, integration and root finding; 91 already contains convexity, unconstrained and constrained optimization. Never duplicate these topics by leaving identical content under both broad and narrow categories. Review a non-overlapping parent/specialized category split or use learning modules below the category if splitting would damage coherence. Five category slots per course is an operational target, not a reason to force a split. Retain IDs and all attempt history; do not automatically move or duplicate existing problems.

Calculus: reuse taxonomy key u-single-calculus as a coherent subject if appropriate, with derivative/integral skill groups; only use two separate categories if the reviewed taxonomy crosswalk supports it. Keep existing multivariable and convergence material. Do not assign unrelated analysis topics just to hit the target.

## Content gates
- Check each proposed topic against the full corresponding CUPM course-area report (including Operations Research for optimization) and actual course prerequisites. Use MSC families only for academic subject indexing.
- Resolve potentially overlapping existing skill labels, e.g. logic IDs 109 and 301, without deleting or merging history automatically.
- Map one primary skill per problem, optional secondary skills; re-audit existing category/skill/track links and published/draft stems. All category splits require a preview, reviewed stable-ID crosswalk, access-policy check and migration plan.
- Author original bilingual conceptual, computational, application and reasoning questions with exact correct answers, four distinct options, meaningful hints and verified structured solutions.
- No empty placeholder categories, no unrelated assignments, no permission changes, no direct database writes.
- Review the 20-question target only after coherent scopes are accepted. Until then the 26 gaps remain planning gaps, not publishable category records.

The proposed modules are intended to guide the next authoring and classification pass; they do not certify the current content or indicate that the bank is complete.
