# G1-09 certificate foundation (policy v1 candidate)

Feature flags `Certificates:Enabled` and `Certificates:IssuanceEnabled` are false by default. Issuance additionally needs LearningSessions enabled. Enable neither in production until reviewed inventory, independently scoped practice cycles, policy approval, client acceptance and privacy review. The proposed conservative policy is all questions in the selected published catalog solved at least once, minimum five questions, four options/one correct and a valid published primary skill on every problem, all required skills represented, independently correct first attempt without hints for each required skill (ordinary official or matching guided practice). A daily challenge alone is insufficient independent evidence. A track certificate requires a published grade/course, category can be stage or track scoped. Never infer academic accreditation. No empty scope earns a certificate.

GET /api/users/certificates lists private immutable issued snapshots; GET eligibility and POST issue accept current stage/track/category, active Premium required. Scope key unique per learner; one issue even across retries. DB transaction + learner lock and consistent snapshot. Certificates retain bilingual subject and name even on reset/stage switch or Premium expiry; downloads only by active owner. Deletion of the learner cascades personal data. GET /api/certificates/verify/{32-hex-code} returns only subject, issue date, policy and scope totals, no identity or IDs. Private PDF includes holder name and high-entropy code in AR/EN with original embedded logo/fonts. Public verification page, revocation policy, certificate client screens, actual PDF rendering/visual QA and email notification remain open. Public verification is not identity matching by itself; recipients may compare the supplied certificate details. No production migration or publishing.

Migration 37 adds private RLS table with revoked API roles. Disposable PostgreSQL tests exercise incomplete scope, real answers, issue/replay, ownership, both PDF languages and preservation. Track certificate and entitlement expiry tests still needed.
