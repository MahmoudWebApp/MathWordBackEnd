## Larger operational runs
Prepare any supported number of validated candidates, partitioned into requests of at most 50 rows (API limit) and 1.8 MB. No per-request manual operation. For existing reviewed catalog drafts, run `node scripts/bank-growth/reviewed-cli.mjs preview plan.json` using an authenticated admin token in MATHWORLD_ADMIN_TOKEN. Review the content and resulting plan before running `node scripts/bank-growth/reviewed-cli.mjs publish plan.json APPROVED_DIGEST 500` with a real MATHWORLD_REVIEW_NOTE. Default 500, max 1000; serial authenticated requests, original revision checks and source/history protections, no automatic retries, confirmed publication journal. Refresh preview on failure or interruption. Never pass tokens on CLI arguments or log them. No production write performed by tests. Hints-only batches and new expansion imports are separate; new candidates must undergo educational review. Do not interpret a matching candidate as proof of pedagogical correctness.
